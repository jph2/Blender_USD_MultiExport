Thank you for your interest in contributing to Blender USD Stable Export! This document provides guidelines and instructions for contributing.

## 🐛 Reporting Bugs

We use GitHub Issues to track bugs. Before creating a bug report, please:

1. **Search existing issues** to ensure the bug hasn't already been reported
2. **Check the documentation** to ensure it's not a usage issue
3. **Test with the latest version** of the addon

### Creating a Bug Report

1. Go to the [Issues](https://github.com/jph2/Blender_USD_MultiExport/issues) page
2. Click "New Issue"
3. Select "🐛 Bug Report" template
4. Fill out all required fields:
   - Clear description of the bug
   - Steps to reproduce
   - Expected vs actual behavior
   - Blender version and OS
   - Screenshots or error logs if available

### Bug Report Checklist

- [ ] Searched existing issues
- [ ] Tested with latest addon version
- [ ] Included Blender version and OS
- [ ] Provided clear reproduction steps
- [ ] Included error messages or screenshots

## 💡 Suggesting Features

We welcome feature suggestions! Before creating a feature request:

1. **Search existing issues** to see if it's already been suggested
2. **Check the roadmap** in the [Research Document](Blender_USD_MultiExport_RESEARCH.md)
3. **Consider the use case** - how would this feature help users?

### Creating a Feature Request

1. Go to the [Issues](https://github.com/jph2/Blender_USD_MultiExport/issues) page
2. Click "New Issue"
3. Select "💡 Feature Request" template
4. Fill out:
   - Problem statement
   - Proposed solution
   - Use case and priority
   - Mockups or examples if available

## 📋 Issue Labels

We use labels to categorize issues:

- `bug` - Something isn't working
- `enhancement` - New feature or improvement
- `question` - Question about usage
- `documentation` - Documentation improvements
- `needs-triage` - Needs review/prioritization
- `help-wanted` - Good for contributors
- `good-first-issue` - Good for new contributors
- `priority: critical` - Critical priority
- `priority: high` - High priority
- `priority: medium` - Medium priority
- `priority: low` - Low priority

## 🤝 Code of Conduct

- Be respectful and constructive
- Provide clear, detailed information in issues
- Search before asking
- Help others when you can

## 📝 Commit Messages

When contributing code (future), follow these guidelines:

- Use clear, descriptive commit messages
- Reference issue numbers when applicable: `Fix #123`
- Follow conventional commits format:
  - `feat:` - New feature
  - `fix:` - Bug fix
  - `docs:` - Documentation changes
  - `refactor:` - Code refactoring
  - `test:` - Test additions/changes
